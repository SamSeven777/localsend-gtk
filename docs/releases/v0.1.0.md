# LocalSend GTK v0.1.0

A fresh release baseline for the unofficial Rust / GTK4 Linux client, using localsend-rs for the LocalSend protocol.

## Included in this release

- Corrected incoming transfer confirmation: clicking **Accept** now accepts the request instead of returning a rejection when the dialog closes. Inline message actions use the same corrected decision handling.
- Removed short `#` device numbers and the hashtag lookup mode. Nearby discovery, full IPv4/IPv6 address entry and favorites remain available.
- Receive-page logo rotation follows the official 15-second turn, pauses when the server stops, and resumes when it starts. Application and system animation preferences are respected.
- Familiar Receive / Send / Settings layout, light and dark themes, system Fontconfig fonts, nine interface languages and compact navigation.
- Native Wayland support, desktop notifications, background receiving, drag and drop, and Nautilus / Dolphin integration.

This is an independent project, not an official LocalSend release. Feature parity and physical-device compatibility testing are ongoing. Thanks to the LocalSend and localsend-rs contributors.

## Downloads and requirements

Native **Linux x86_64** packages are provided as DEB, RPM and tar.gz, together with `SHA256SUMS`. They require **glibc 2.39+, GTK 4.12+ and libadwaita 1.5+**. The tar archive does not bundle these libraries.

- Debian/Ubuntu: `sudo apt install ./localsend-gtk_0.1.0-1_amd64.deb`
- Fedora: `sudo dnf install ./localsend-gtk-0.1.0-1.x86_64.rpm`
- Tar archive: extract it and run `sudo ./install.sh`, or `./install.sh "$HOME/.local"` for the current user.

**Existing 1.x installations:** version numbering has been reset, so package managers may require an explicit downgrade. Use `sudo apt install --allow-downgrades ./localsend-gtk_0.1.0-1_amd64.deb` or `sudo dnf downgrade ./localsend-gtk-0.1.0-1.x86_64.rpm`. Keep your existing configuration; the reset does not require deleting it.

The repository includes an AUR packaging recipe and a Flatpak manifest; this release does not claim publication on AUR or Flathub. Flatpak login autostart remains unavailable until background-portal integration is implemented.

## Validation

Validation includes real consent-button activation, HTTPS upload with saved-content verification, inline messages, animation frame comparisons and pause/resume behavior, unit tests, and Wayland interface tests. The receive bug was reproduced against an existing remote GTK installation before the fix; a Windows official-client transfer to the updated installation still needs to be repeated.
